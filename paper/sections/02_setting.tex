\section{Setting and Candidate Evidence Frames}
\label{sec:setting}

\paragraph{Active selection.}
Let $\mathcal{X}=\{x_1,\ldots,x_N\}$ be an unlabeled evaluation pool and $E=\{e_1,\ldots,e_H\}$ the submitted entries. Entry $e$ exposes response vector $a_e$ and has oracle utility vector $u_e$, binary per-example correctness in our experiments. An active policy $\pi$ acquires $B$ references and produces a transcript of queried indices, references, and entry decisions. Using an oracle root map for analysis, we evaluate the corresponding accountable-root choices $\widehat r_1,\ldots,\widehat r_B$.

\begin{definition}[Candidate evidence frame]
A frame $\Phi=(R,\rho,w)$ maps entries to accountable roots through $\rho:E\rightarrow R$ and assigns root mass $w_r$. A root is the unit that the evaluation claim intends to count once; it need not be observable or authenticated. Two frames are \emph{response-compatible} when they expose the same entry identifiers and response vectors.
\end{definition}

\begin{definition}[Registry refinement]
A refinement of root $r$ adds entries mapped to $r$ without modifying existing entries. It is \emph{exact} when an added response vector copies its parent and \emph{quality-equivalent} when its utility vector equals the parent's coordinate-wise, even if responses differ.
\end{definition}

A uniform entry mechanism induces $\mu_E=|E|^{-1}\sum_{e\in E}\delta_{a_e}$, so adding entries changes one root's represented mass without adding an accountable alternative. A policy is \emph{frame-blind} when it observes responses and acquired references but not authenticated $\rho$ or $w$. Prior work separately studies known-owner duplicate arms, static clone weighting, redundant sequential committees, arena candidates, false names, and model lineage; Section~\ref{sec:related} explains why none supplies the complete latent-root, shared-label acquisition object considered here. We claim neither the first clone effect nor a new lineage system.

\paragraph{Natural and adversarial refinements.}
The natural anchor restores an exact-response version alias to its frozen quotient and makes no claim of common control or adversarial intent. The intervention tiers are separate. \textbf{T0} adds exact copies as a mechanism/defense control. \textbf{T1} learns from disjoint calibration references and receives only holdout inputs and parent outputs. \textbf{T2}, the main causal test, changes only parent-wrong responses using public or independently acquired references, preserving correctness exactly. Across tiers, the attacker cannot modify existing entries, selector code, pool, budget, temperature, seeds, tie rules, or adapt after acquisition begins.

Let $\ell(r)$ be root $r$'s full-pool loss and $r^*$ a best root. We report ordered-path divergence, terminal regret $\ell(\widehat r_B)-\ell(r^*)$, and
\[
\operatorname{CReg}_B=\sum_{t=1}^{B}\bigl[\ell(\widehat r_t)-\ell(r^*)\bigr].
\]
Cumulative regret captures repeated interim use; terminal regret prevents a transient path change from being reported as a worse final model choice.
