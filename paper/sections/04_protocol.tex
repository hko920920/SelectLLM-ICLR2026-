\section{Causal Intervention and Evaluation}
\label{sec:protocol}

\paragraph{Primary mechanism.}
Select-LLM uses one similarity $s$ for both reference--output posterior evidence and output--output acquisition \citep{durmazkeser2026selectllm}. Our exact-answer specialization sets $s(a,b)=\mathbf 1[a=b]$ in both places:
\[
p_t(e)\propto\exp\!\left(\tau^{-1}\!\sum_{s<t}s(r_{i_s},a_e(x_{i_s}))\right),\qquad
A_t(x)=\sum_y\left(\sum_{e:a_e(x)=y}p_t(e)\right)^2.
\]
The selector queries the item minimizing $A_t$, observes its reference, and chooses the root with maximum accumulated exact-match evidence. This source-fidelity statement applies to the natural anchor and primary T2 experiment; deliberately decoupled transfer audits are labeled as such. Canonical ordering by response hash, root ID, and label hash removes submitted-list order as a paired-run determinant.

We use frozen HELM-Lite v1.0.0 responses for 31 models \citep{liang2023helm} on MedQA, GSM8K, and OpenBookQA \citep{jin2021medqa,cobbe2021gsm8k,mihaylov2018openbookqa}.

\paragraph{Evidence ladder.}
The layers answer different questions and are not pooled as interchangeable attacks. The existing exact alias tests occurrence. T2 uses response-distinct, exactly utility-preserving variants to identify candidate-mass causality under public/acquired-reference access. T1 uses calibration-only abstention variants on untouched holdouts. Learned raw-text endpoints use train/development labels but no outcome lookup at deployment, and the official LLM Selector audit tests a second acquisition family. Table~\ref{tab:result-ladder} reports their distinct conclusions.

\paragraph{Natural and exact-quality interventions.}
Before selector outcomes, row equality identifies the unique complete response-and-utility pair. The 30-entry quotient removes the later version and the natural roster restores it as the same root (Appendix~\ref{app:natural}). T2-A adds four response-distinct aliases: a frozen hash selects parent-wrong coordinates, and each alias substitutes another wrong option or a nonzero numeric offset. Thus $u_{e'}=u_e$ coordinate-wise. Construction reads the parent output, public item information, and references, but no peer response, pool, or trajectory; targets are selected on disjoint development pools and replayed without retargeting on 500 fresh pools per task. Runtime wrappers receive no item ID, reference, peer output, pool seed, or selector state (Appendix~\ref{app:llmprotocol}).

\paragraph{Outcome-free transfer.}
T1 freezes eight untouched QA/translation scenarios before holdout outcomes and builds four aliases from calibration-only TF--IDF error scores; the deployed wrapper receives no holdout reference or utility. Because acquisition uses exact response while evidence uses F1/BLEU, this is a decoupled-view audit (Appendix~\ref{app:step87b}). Learned audits restore one literal exact-match view: a raw-input adapter emits its parent's label or an out-of-label abstention token. The main IMDB condition is selected on 12,000 development rows and bound, including all label-free held-out predictions, weights, thresholds, code, seeds, and outcome hash, before a disjoint 13,000-row outcome opens. Yelp inherits that recipe with one public-checkpoint roster and no target selector search (Appendices~\ref{app:step104}--\ref{app:step105}).

\paragraph{Controls, inference, and defenses.}
Clean/refined pairs share pool, references, budget, temperature, and tie rules. Candidate-invariant random queries test nonvacuity; a fixed query matrix isolates acquisition mediation; 16 registry permutations and all nine exact query/root tie policies test implementation dependence. We report paired terminal and cumulative root regret, path/query-set change, and final-root transitions. Intervals use 10,000 paired bootstrap repetitions, sign-flip tests are paired, and prespecified families are multiplicity-corrected; complete grids and negative outcomes remain in the appendix. Defenses compare exact quotienting, behavioral covers, authenticated-root mass, and clone-robust graph weights \citep{berriaud2026consensus}, jointly measuring residual attack and clean cost. CODA and all six official LLM Selector datasets provide second-family audits (Appendices~\ref{app:defense}, \ref{app:coda}, and~\ref{app:step88}).
