\begin{abstract}
Active model selection uses candidate outputs to decide which costly labels to acquire. In candidate-indexed mechanisms, however, every listed entry receives separate mass, so two registries encoding the same accountable models can define different experiments. We formalize the missing \emph{candidate evidence frame}: accountable roots, an entry-to-root map, and a root-mass rule. We prove a tight annotation-budget-linear cost when this frame is unobserved and give a constant-size Select-LLM construction that redirects an entire acquisition transcript. A natural exact version alias changes all 1,500 paired paths without adding behavior, although it causes no reliable terminal harm. Controlled response-distinct aliases then preserve correctness coordinate-wise while increasing root-level regret; forcing clean and refined registries to use the same queries makes every effect exactly zero, isolating acquisition mediation. Raw-text learned endpoints provide a separate development-informed held-out confirmation on IMDB without held-out-reference lookup. Transfer is deliberately not universal: a prospective Yelp effect and zero-utility CIFAR refinements change most paths but remain below predeclared terminal-materiality thresholds, while several other audits are null or beneficial. Authenticated root mass with refinement-invariant root summaries restores transcript invariance. We therefore identify an experimental-unit failure in active evaluation, not a universal attack, live-registry compromise, or guarantee of practically large harm.
\end{abstract}
