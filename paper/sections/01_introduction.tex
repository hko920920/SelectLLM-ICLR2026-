\section{Introduction}
\label{sec:introduction}

Expert labels are costly, so DiffUse, MODEL SELECTOR, CODA, LLM Selector, and Select-LLM use candidate outputs, weak judges, or consensus to decide which examples to label for model comparison \citep{ashurytahan2024diffuse,okanovic2025modelselector,kay2025coda,durmazkeser2025llmselector,durmazkeser2026selectllm}. These methods can be highly label-efficient. Yet candidate-indexed implementations assign posterior or consensus mass to every listed entry. They rarely state what should remain invariant when two submitted lists encode the same underlying model alternatives.

The missing object is the \emph{candidate evidence frame}: a set of accountable \emph{roots}, a map from submitted \emph{entries} to roots, and a rule for assigning root mass. A root is the unit that an evaluation claim intends to count once---for example, one independently accountable model lineage---whereas an entry is merely what a registry accepts. Predictions alone need not reveal common ownership or derivation. Treating entries as the population can therefore make registry representation part of the experiment: entry mass affects the next label request, the acquired label updates every entry, and the changed evidence can alter the final root choice.

This object is adjacent to, but not subsumed by, several clone and replication literatures. Strategic-replication bandits study duplicate arms under supplied agent ownership and arm-local rewards \citep{shin2022strategicreplication,shin2025replicationproof}. Clone-robust alignment and metric weighting study static learning or aggregation under near-duplicate alternatives \citep{procaccia2025clonerobust,berriaud2026consensus}. UNREAL and active-evaluation work address redundant or perturbed candidates in sequential settings \citep{nguyen2025unreal,lanctot2026activeevaluation}, while arena and leaderboard studies analyze candidacy or ranking sensitivity \citep{singh2025leaderboard,huang2026dropping,hays2026strategic}. Our remaining object is their shared-label, latent-root boundary: one label is reusable evidence for all entries, entry mass changes which future labels exist, and the endpoint is root-level model selection. A static score can be recomputed after quotienting; an acquisition transcript cannot recover labels that were never requested. A fixed-query counterfactual lets us test this adaptive mediation directly.

The issue occurs naturally. In a frozen 31-model roster, \texttt{claude-instant-1.2} and \texttt{claude-instant-v1} have identical responses and utilities on all 2,500 task items. Restoring the second entry to its 30-entry response quotient adds no behavior, but changes every one of 1,500 Select-LLM acquisition paths; candidate-invariant random querying is unchanged. Unique-label replacement is nevertheless small and terminal harm is absent. The natural pair therefore establishes representation dependence, not a prevalent attack or broad natural damage.

We then isolate the causal channel. Four response-distinct T2 aliases preserve their parent's correctness on every item while all existing candidates, references, pools, code, and root utilities remain fixed. They raise cumulative root regret on MedQA, GSM8K, and OpenBookQA and terminal regret on the first two. When clean and refined registries are forced to acquire the same labels, their root histories and regret arrays are exactly equal. This removes static roster composition as an explanation: the effect travels through acquisition $\rightarrow$ reusable evidence $\rightarrow$ root decision.

A separate evidence ladder tests how far that channel transfers without target-outcome lookup. Calibration-only variants pass three of eight untouched scenarios; raw-text learned adapters yield a $+.702$-point terminal effect on a disjoint 13,000-row IMDB outcome under the same exact-match acquisition/evidence view. This is development-informed held-out confirmation, not before-all-data task transfer. A stricter one-shot Yelp audit is positive but below its predeclared materiality threshold. Post-V20 zero-utility CIFAR refinements change roughly 95--98\% of paths and retain exact fixed-query and authenticated-root controls, yet their largest CIFAR-100 terminal effect is only $+.181$ points (Appendix~\ref{app:v21-postv20}). Thus transcript dependence transfers more broadly than practically material terminal harm.

Our contributions are:
\begin{enumerate}
    \item We define candidate evidence frames and prove both a tight budget-linear cost of a missing frame and a constant-size full-path amplification for a concrete selector.
    \item Exact-quality interventions and fixed-query counterfactuals establish the complete refinement $\rightarrow$ acquisition $\rightarrow$ evidence $\rightarrow$ root-cost chain; a natural version alias anchors the unit problem in an existing roster.
    \item Outcome-free endpoints, second-family audits, retained negative transfers, and root-aware controls map the boundary: the mechanism is real but selective, while authenticated root mass and refinement-invariant summaries restore the intended experimental unit.
\end{enumerate}

We do not claim the first clone effect, that every active selector is vulnerable, that every refinement is harmful, that response similarity authenticates ownership, or that our offline endpoints demonstrate production compromise. The reliability requirement is narrower: an active evaluation should bind entries to a declared candidate evidence frame, or report multiplicity sensitivity as uncertainty in the resulting selection claim.
