any numerical evidence or replacing the preregistered Banking77 negative.

## 1. Strategic-replication boundary

The manuscript now directly compares the candidate-evidence-frame object with:

- Shin, Lee, and Ok (2022), *Multi-armed Bandit Algorithm against Strategic
  Replication*, https://proceedings.mlr.press/v151/shin22a.html; and
- Shin, Esmaeili, and Hajiaghayi (2025 revision), *Replication-proof Bandit
  Mechanism Design with Bayesian Agents*, https://arxiv.org/abs/2312.16896.

The overlap is registered multiplicity before sequential allocation and its
regret consequence. The remaining distinction is explicit in the Introduction,
Table 1, and Related Work: the bandit line is given agent/arm ownership and
observes reward only for the pulled arm, whereas this manuscript has a latent
root map, one acquired reference label scores every candidate entry, and the
downstream object includes terminal root/model selection. The manuscript claims
neither the first sequential replication nor the first clone effect.
